# Photo Bot

Product poster maker: frame + product photo → AI background removal → effects → English & Dhivehi names → save to Photos or send to Telegram.

## Telegram setup (Vercel → Settings → Environment Variables)
- `TELEGRAM_BOT_TOKEN` — from @BotFather (required)
- `PHOTOBOT_PIN` — optional PIN required to send
- `TELEGRAM_CHAT_ID` — optional fixed group id (otherwise pick the group in the app's ⚙)

Redeploy after changing variables.
